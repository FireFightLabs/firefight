# Beautiful UI components

Vendored from <https://www.beautifului.dev>, which publishes a shadcn-format registry:

```
npx shadcn add https://www.beautifului.dev/r/<name>.json
```

The files here were taken from that registry and kept close to source, so an update is a re-pull plus
the edits below rather than a rewrite. They are outside eslint (like `components/ui/`) because they
are not ours to reformat. Their tokens live in `app/frontend/styles/agent-ui.css`, scoped to
`.agent-ui`, which the agent page carries.

| File | Registry item | Our edits |
|---|---|---|
| `loading-state.tsx` | `loading-state` | Dropped the Surfer variant, which streams a meme video from their CDN, and the `variant` prop nobody passed, so it is always Drive. |
| `approval-card.tsx` | `approval-card` | A single question sends on the first click and hides the footer, since there is nothing to step through. Added `allowCustom` to turn off the "Something else" row. `send` takes the answers it sends, so the auto advance after the last choice sends that choice, where the original sent the answers from before the click. Imports point at `button.tsx` and `glide-menu.tsx` here. Dropped the `variant` prop nobody passed. The sent check draws its mark in `text-canvas`, the dark ink, rather than white, since the green fill behind it is light. It sends only once every question has an answer: a pick, Continue and Skip all move to the next question still open, wrapping round, and the button reads Send only when none is left, where the original sent the moment the last question was answered and left any skipped one unanswered. Added `answerAlike`, so one pick can answer other questions too, which allowing a tool for the rest of a chat needs. |
| `button.tsx` | `button` | Flat: dropped the white inset highlight on filled buttons. `primary` is the app's off-white primary button with dark text, darker on hover and press. `accent` and `success` are lime with dark text, lighter on hover, darker on press, where the original put white text on them. `secondary` hovers onto the hover surface. Added `motion-reduce` variants so the press scale and transitions stop under reduced motion. |
| `glide-menu.tsx` | `glide-menu` | None, it is what the approval card is built from. |
| `thinking-state.tsx` | `thinking-state` | Kept the Steps variant and dropped Reasoning, Search and Coding, which are demos of things we do not have yet. The trace is driven by props rather than by its own timer: rows show as they are given, `working` shimmers the header and spins the last row, and `done` carries our own wording. Dropped the fixed `minHeight`, which held their demo open. Added `open`, which holds the trace open between two steps of a live turn without spinning a row, since the trace otherwise closed and reopened in the gap and the thread jumped with it. A row carries its own `status`, drawn as a mark (spinner, check, cross, pause, slash) with the word for screen readers, and optional `details` that open under it (drawn by our own `components/detail-list.tsx`, which is not from the registry), so one trace holds a turn's every step where reads and actions used to alternate with `task-rows`. A row can carry an `outcome` drawn when opened, a `live` node shown under it whether or not it is opened, and `quiet` for a line such as Halon making room. Rows already there when the trace mounts appear at rest, only new ones fade in. A long secondary line truncates rather than pushing past the edge, and the trace is `max-w-2xl` rather than `max-w-95`. |
| `prompt-bar.tsx` | `prompt-bar` | Dropped the `glimm` WebGL sweep, which played on model change, the self running demo with its sample sources and commands, and the Pill variant nobody passed. `sources` and `commands` are required, since a default would be sample data. Dictation stays, switched off by a prop until there is something behind it. The model picker is real: `models` hands it the caller's options (a name, a few words under it and an optional tag such as Default), the one in use and `onSelect`, the sample models are gone, the menu is wider to fit the words, and its rows are a menu of radio items. Without `models` there is no picker. Attachments are real: the sample file names are gone, `attachments` hands the bar the caller's uploads (name, size, a preview for an image, progress, an error or a note) and takes `onAdd` and `onRemove`, the + menu leads with an Attach files row that opens the file picker, a drag carrying files lights the composer and drops them in, and a pasted screenshot is attached while pasted text still lands in the input. Send waits while a file uploads or has failed. Added `sources`, `commands` and `dictation` props, so a control with nothing behind it yet is off rather than shown and dead, and a menu with nothing in it does not open. Added `onStop`, which turns Send into Stop while nothing is typed. Added `onSourceSearch`, which hands the @ query to the caller so it can search the server, and then shows `sources` as given rather than filtering them again. Added `sourceHint`, the line under the @ menu, since ours finds incidents and not files. Added `initialDraft` and `autoFocus`, so a new chat can hand it an example question to finish with the caret already in place. Dropped the Figma, Slack and Gmail marks and the `brand` field on a source, which no source of ours sets, so the file carries no colour outside the palette. The composer sits on the input surface with a strong edge, and focus turns that edge to the control border rather than a shadow. Links in the @ menu and the dictation button's listening state use `text-accent`, since `accent-ink` is now the dark text that sits on lime. |

Not vendored yet, and worth taking when there is something behind it: `streaming-text` (needs sources
and follow-ups).
