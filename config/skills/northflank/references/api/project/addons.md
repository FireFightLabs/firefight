# addons

Paths written after /v1/projects/{projectId}/. Every endpoint here is from @northflank/js-client 0.11.0.

### GET addons

Gets a list of addons belonging to the project.
Query: per_page, page, cursor.
Permission: Project > Addons > General > Read.

### POST addons

Creates a new addon.
Body, required: one of {name, type, version, billing.deploymentPlan, billing.storage, billing.replicas} or {name, type}.
Body, optional: description, projectId, stageId, tags, infrastructure, source, tlsEnabled, externalAccessEnabled, vpcAccessible, ipPolicies[], typeSpecificSettings, customCredentials, backupSchedules[], metadata, templateValues, region.
Permission: Project > Addons > General > Create.

### PUT addons

Creates or updates an addon.
Body, required: one of {name, type, version, billing.deploymentPlan, billing.storage, billing.replicas} or {name, type}.
Body, optional: description, projectId, stageId, tags, infrastructure, source, tlsEnabled, externalAccessEnabled, vpcAccessible, ipPolicies[], typeSpecificSettings, customCredentials, backupSchedules[], metadata, templateValues, region.
Permission: Project > Addons > General > Create.

### GET addons/{addonId}

Gets information about the given addon.
Permission: Project > Addons > General > Read.

### PATCH addons/{addonId}

Updates an addon.
Body, optional: description, stageId, tags, version, billing, tlsEnabled, externalAccessEnabled, vpcAccessible, ipPolicies[], typeSpecificSettings, backupSchedules[], metadata, templateValues.
Permission: Project > Addons > General > Update.

### DELETE addons/{addonId}

Deletes the given addon.
Permission: Project > Addons > General > Delete.

### GET addons/{addonId}/backup-schedules

Gets details about an addon's backup schedules.
Query: per_page, page, cursor.
Permission: Project > Addons > General > Read.

### POST addons/{addonId}/backup-schedules

Create a new backup schedule for an addon.
Body, required: scheduling.interval, scheduling.minute, backupType, retentionTime.
Body, optional: customDestinationId, additionalDestinations[], compressionType.
Permission: Project > Addons > General > Update.

### DELETE addons/{addonId}/backup-schedules/{scheduleId}

Deletes a backup schedule for an addon.
Permission: Project > Addons > General > Update.

### GET addons/{addonId}/backups

Returns a list of backups for the given addon.
Query: per_page, page, cursor.
Permission: Project > Addons > General > Read.

### POST addons/{addonId}/backups

Initiates a backup for the given addon.
Body, optional: name, backupType, compressionType, customDestinationId, additionalDestinations[].
Permission: Project > Addons > General > Update.

### GET addons/{addonId}/backups/{backupId}

Gets details about a given backup.
Permission: Project > Addons > General > Read.

### DELETE addons/{addonId}/backups/{backupId}

Deletes a given backup.
Permission: Project > Addons > General > Update.

### POST addons/{addonId}/backups/{backupId}/abort

Aborts the in progress backup.
Permission: Project > Addons > General > Update.

### POST addons/{addonId}/backups/{backupId}/abort-restore

Aborts an in-progress backup restore.
Body, required: restoreId.
Query: sourceProjectId, sourceAddonId.
Permission: Project > Addons > General > Update.

### GET addons/{addonId}/backups/{backupId}/download-link

Generates a temporary download link for downloading the given backup.
Permission: Project > Addons > General > Read.

### POST addons/{addonId}/backups/{backupId}/restore

Restores the given addon to the given backup state.
Query: sourceProjectId, sourceAddonId.
Permission: Project > Addons > General > Update.

### GET addons/{addonId}/backups/{backupId}/restores

Gets a list of restores for the given backup.
Query: per_page, page, cursor, sourceProjectId, sourceAddonId.
Permission: Project > Addons > General > Read.

### POST addons/{addonId}/backups/{backupId}/retain

Flags a temporary backup generated by a backup schedule to be retained indefinitely rather than being deleted after the expiry date.
Permission: Project > Addons > General > Update.

### GET addons/{addonId}/containers

Gets a list of containers for the given addon.
Query: per_page, page, cursor.
Permission: Project > Addons > General > Read.

### GET addons/{addonId}/credentials

Returns the credentials for connecting to the given addon.
Permission: Project > Addons > General > Read.

### POST addons/{addonId}/import

Imports a database from an external archive or existing live database.
Body, required: one of {connectionString} or {importUrl}.
Body, optional: name, importAllDatabases, compressionType, customDestinationId.
Permission: Project > Addons > General > Update.

### POST addons/{addonId}/network-settings

Updates the network settings for the addon.
Body, optional: tlsEnabled, externalAccessEnabled, vpcAccessible.
Permission: Project > Addons > General > Update.

### POST addons/{addonId}/pause

Pause the given addon.
Permission: Project > Addons > General > Update.

### POST addons/{addonId}/reset

Reset the given addon.
Permission: Project > Addons > General > Delete.

### POST addons/{addonId}/restart

Restart the given addon.
Permission: Project > Addons > General > Update.

### GET addons/{addonId}/restores

Returns a list of restores for the given addon.
Query: per_page, page, cursor.
Permission: Project > Addons > General > Read.

### POST addons/{addonId}/resume

Resume the given addon if it is paused.
Permission: Project > Addons > General > Update.

### POST addons/{addonId}/scale

Modifies the allocated resources for the given addon.
Body, optional: deploymentPlan, storage, replicas.
Permission: Project > Addons > General > Update.
Deprecated: Requests should instead use the relevant PATCH endpoint. Replacement: /addons/patch-addon.

### POST addons/{addonId}/secret-rotation

Starts a secret rotation for the given addon. New credentials are created with the same permissions; the old credentials remain valid until the rotation is finalised.
Permission: Project > Addons > General > Update.

### POST addons/{addonId}/secret-rotation/finalise

Finalises an in-progress secret rotation for the given addon. The old credentials are permanently removed.
Permission: Project > Addons > General > Update.

### POST addons/{addonId}/security

Updates the security rules for the addon.
Body, required: ipPolicies[].address.
Permission: Project > Addons > General > Update.

### GET addons/{addonId}/version

Gets details about the current addon version including available upgrades and upgrade history.
Permission: Project > Addons > General > Read.

### POST addons/{addonId}/version

Upgrades the addon to a new version.
Body, required: version.
Permission: Project > Addons > General > Update.
