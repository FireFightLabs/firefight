# pipelines

Paths written after /v1/projects/{projectId}/. Every endpoint here is from @northflank/js-client 0.11.0.

### GET pipelines

Lists all pipelines for a project.
Query: per_page, page, cursor.
Permission: Project > Pipelines > General > Read.

### GET pipelines/{pipelineId}

Get details about a pipeline.
Permission: Project > Pipelines > General > Read.

### GET pipelines/{pipelineId}/preview-envs

Get information about the given preview template.
Query: per_page, page, cursor.
Permission: Account > Templates > General > Read.

### POST pipelines/{pipelineId}/preview-envs

Update a given preview template.
Body, required: apiVersion, spec.
Body, optional: options, arguments, gitops, $schema, paused, triggers[], webhook.
Permission: Account > Templates > General > Create.

### GET pipelines/{pipelineId}/preview-envs/previews

Get a list of active preview environments for a template.
Query: per_page, page, cursor.
Permission: Account > Templates > General > Read.

### DELETE pipelines/{pipelineId}/preview-envs/previews/{previewId}

Delete a preview environment generated by a preview template.
Body, optional: teardownArgumentOverrides.
Query: skipTeardown.
Permission: Account > Templates > General > Delete.

### GET pipelines/{pipelineId}/preview-envs/runs

Get a list of preview template runs.
Query: per_page, page, cursor, status, concluded.
Permission: Account > Templates > General > Read.

### POST pipelines/{pipelineId}/preview-envs/runs

Run the given preview template.
Body, optional: name, arguments, triggers.
Permission: Account > Templates > General > Create.

### GET pipelines/{pipelineId}/preview-envs/runs/{templateRunId}

Get information about the given preview template run.
Permission: Account > Templates > General > Read.

### GET pipelines/{pipelineId}/release-flows/{stage}

Gets details about a release flow.
Permission: Project > Pipelines > General > Read.

### POST pipelines/{pipelineId}/release-flows/{stage}

Updates a release flow.
Body, required: apiVersion, spec.
Body, optional: arguments, triggers[], options, gitops, $schema, richInputs, teardownSpec, project.
Permission: Project > Pipelines > General > Update.

### GET pipelines/{pipelineId}/release-flows/{stage}/runs

Lists runs of a release flow.
Query: per_page, page, cursor, status, concluded.
Permission: Project > Pipelines > General > Read.

### POST pipelines/{pipelineId}/release-flows/{stage}/runs

Runs a given release flow with given arguments. This endpoint can be used as part of a CI pipeline to automatically trigger a release process.
Body, optional: name, description, arguments, overrides, releaseNodeOverrides.
Permission: Project > Pipelines > General > Update.

### GET pipelines/{pipelineId}/release-flows/{stage}/runs/{runId}

Get information about the given release flow run.
Permission: Project > Pipelines > General > Read.

### POST pipelines/{pipelineId}/release-flows/{stage}/runs/{runId}/abort

Abort the given release flow run.
Permission: Project > Pipelines > General > Update.
