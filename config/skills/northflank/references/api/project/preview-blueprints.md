# preview-blueprints

Paths written after /v1/projects/{projectId}/. Every endpoint here is from @northflank/js-client 0.11.0.

### GET preview-blueprints

Lists all preview blueprints for a project.
Query: per_page, page, cursor.
Permission: Project > PreviewBlueprints > General > Read.

### POST preview-blueprints

Create a preview blueprint.
Body, required: name, apiVersion, spec.
Body, optional: arguments, gitops, $schema, description, options, argumentOverrides, teardownSpec, triggers, project.
Permission: Project > PreviewBlueprints > General > Create.

### GET preview-blueprints/{previewBlueprintId}

Gets details about a preview blueprint.
Permission: Project > PreviewBlueprints > General > Read.

### POST preview-blueprints/{previewBlueprintId}

Updates a preview blueprint.
Body, required: name, apiVersion, spec.
Body, optional: arguments, gitops, $schema, description, options, argumentOverrides, teardownSpec, triggers, project.
Permission: Project > PreviewBlueprints > General > Update.

### DELETE preview-blueprints/{previewBlueprintId}

Delete a preview blueprint.
Permission: Project > PreviewBlueprints > General > Delete.

### GET preview-blueprints/{previewBlueprintId}/previews

Get a list of active previews for a preview blueprint.
Query: per_page, page, cursor.
Permission: Project > PreviewBlueprints > General > Read.

### DELETE preview-blueprints/{previewBlueprintId}/previews/{previewId}

Delete a preview environment generated by a preview blueprint.
Body, optional: teardownArgumentOverrides.
Query: skipTeardown.
Permission: Project > PipelinesV2 > Previews > Delete.

### POST preview-blueprints/{previewBlueprintId}/previews/{previewId}/pause

Pause a preview environment generated by a preview blueprint.
Permission: Project > PipelinesV2 > Previews > Pause.

### POST preview-blueprints/{previewBlueprintId}/previews/{previewId}/reset

Reset the expiry of a preview environment generated by a preview blueprint.
Body, optional: lifetime.
Permission: Project > PreviewBlueprints > General > Update.

### POST preview-blueprints/{previewBlueprintId}/previews/{previewId}/resume

Resume a preview environment generated by a preview blueprint.
Permission: Project > PipelinesV2 > Previews > Resume.

### GET preview-blueprints/{previewBlueprintId}/runs

Lists runs of a previewBlueprint.
Query: per_page, page, cursor, status, concluded.
Permission: Project > PreviewBlueprints > Runs > Read.

### POST preview-blueprints/{previewBlueprintId}/runs

Runs a given preview blueprint with given arguments. This endpoint can be used as part of a CI pipeline to automatically create a preview environment.
Body, optional: name, description, arguments, triggers.
Permission: Project > PreviewBlueprints > Runs > Start.

### GET preview-blueprints/{previewBlueprintId}/runs/{runId}

Get information about the given preview blueprint run.
Permission: Project > PreviewBlueprints > Runs > Read.

### POST preview-blueprints/{previewBlueprintId}/runs/{runId}/abort

Abort the given preview blueprint run.
Permission: Project > PreviewBlueprints > Runs > Abort.
